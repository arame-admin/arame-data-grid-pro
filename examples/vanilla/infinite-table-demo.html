1. Incremental Ingestion (Infinite Scroll)

Fetches data lazily in chunks (e.g. 25 rows) as the user approaches the bottom of the table. Minimizes initial network payload and server memory pressure. Uses request locks, query resets, and AbortSignal cancellation.

2. DOM Row Virtualization (Optional)

Recycles and mounts only the rows currently visible within the viewport (plus overscan padding). Keeps DOM node count fixed (~20 nodes) even when 10,000+ items are accumulated in memory, eliminating browser rendering lag.

💡 How to Use Infinite Scrolling

Configure continuous asynchronous pagination with prefetching and client/server search and sorting:

1. Supply Data Loader Function

Pass an asynchronous data-fetching callback supporting startIndex, limit, and signal. 

table.dataLoader = async ({ startIndex, limit, signal }) => {
  const res = await fetch(`/api/data?offset=${startIndex}&limit=${limit}`, { signal });
  return await res.json();
};

2. Threshold & Virtualization

Tune distance prefetching via thresholdPx and toggle DOM node virtualization on high-volume datasets. 

table.options = {
  thresholdPx: 200,
  virtualization: true,
  batchSize: 25
};
