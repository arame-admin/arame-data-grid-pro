Calculated Payroll Data Table (Enterprise Compensation Studio)

A professional, real-time reactive compensation & payroll calculation table. Edit Base Salary, Bonus %, Overtime Hours, or 401(k) Contribution to instantly recalculate Gross Compensation, Tax Withholdings, Benefit Deductions, and final Net Take-Home Pay.

💡 How to Use Calculated Tables

Calculated tables execute reactive mathematical formulas across row fields whenever editable dependencies change.

1. Reactive Calculated Columns

Assign a calculate: (row) => number function to compute values dynamically from editable inputs. 

{
  key: 'grossComp',
  header: 'Gross Compensation',
  calculate: (r) => r.baseSalary + (r.baseSalary * (r.bonusPct / 100))
}

2. Dual Sticky Pinned Columns

Lock both the first column (Employee) and the final calculated column (Net Take-Home Pay) for seamless wide comparison. 

table.options = {
  sticky: { stickyFirst: true, stickyLast: true }
};
