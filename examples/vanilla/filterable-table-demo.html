Narrow records using a global search and dedicated per-column filters: Text search (Client), Select dropdown (Status), Number range (Amount min/max), and Date range (Invoice Date start/end).

💡 How to Use Column Filtering

Multi-Column Filtering combines instant debounced global searching with per-column controls like text matching, single/multi-select dropdowns, number min/max ranges, and date boundaries.

1. Define Column Filter Types

Assign filter: 'text' | 'select' | 'number-range' | 'date-range' in your column configuration. 

{ id: 'status', filter: 'select', filterOptions: ['Paid', 'Pending'] }
{ id: 'amount', filter: 'number-range' }

2. Filter Count & Reset

Active filter count badges automatically increment and decrement, with single-click "Clear All Filters" resetting all inputs. 

table.clearFilters(); // Resets all column filters & searches
