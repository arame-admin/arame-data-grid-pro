💡 How to Use Row Grouping

Hierarchical row grouping organizes flat tabular datasets into expandable branches with aggregate mathematical calculations across children.

1. Single or Multi-Level Grouping

Pass an array of field names to table.groupBy to enable single or multi-tier grouping trees. 

table.groupBy = ['department', 'team'];

2. Automatic Aggregate Summaries

Define columns with aggregate: 'sum' | 'avg' | 'count' | 'min' | 'max' to calculate header and footer subtotals. 

{ id: 'salary', aggregate: 'sum', formatter: formatCurrency }
