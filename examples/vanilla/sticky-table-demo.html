Sticky First Column Data Table

The first column (Product Name) remains locked at the edge while all other specification columns scroll horizontally. Supports edge drop-shadow on scroll, column resizing, RTL direction toggling, and sorting.

📌 How to Use Sticky Columns

Sticky column pinning allows key identifier columns (such as Product Name, Employee ID, or Model) to remain persistently fixed to the viewport edge during wide horizontal table scrolling.

1. Enable Sticky Attribute

Add the sticky-first-column="true" attribute to the custom element tag or toggle it dynamically via JavaScript. 

<sticky-data-table
  id="my-table"
  sticky-first-column="true">
</sticky-data-table>

2. Scroll Elevation Shadows

When the user scrolls horizontally, the table container adds st-is-scrolled to cast an elevation shadow along the pinned edge to clearly demarcate boundary depth. 

.st-scroll-viewport.st-is-scrolled .st-col-sticky {
  box-shadow: 4px 0 8px -2px rgba(0,0,0,0.15);
}

3. RTL & Column Resizing

Fully respects dir="rtl" by anchoring the column to the right boundary with inverted drop-shadows and mirrored column resizer handles. 

tableEl.setAttribute('dir', 'rtl');
