💡 How to Use the Advanced Filter Table

This table combines enterprise multi-level row grouping, pinned columns, master-detail drawers, editable cells with validation, and Boolean expression trees. Here is how each component is used:

1. Hierarchical Row Grouping

Group by single or multiple fields (e.g. Category > Brand) with auto-calculated summaries for item counts, sum of revenue, and stock totals. 

table.groupBy = ['category', 'brand'];

2. Column Visibility Controls

Click Columns ▼ to toggle column visibility checkboxes, hide optional columns, or restore defaults. Key columns can be locked to prevent hiding. 

// Locked column config
{ id: 'sku', header: 'SKU', locked: true }

3. Inline Editing & Validation

Double click cells (or click the edit pencil icon) to modify values in-place. Validates input types (e.g., positive numbers for price) before persisting. 

table.addEventListener('aft:cell-save', (e) => {
  console.log('Saved:', e.detail);
});

4. Filter Builder & Chips

Open Filter Builder to craft compound rules with AND / OR logic. Active rules appear in the chips bar and can be deleted individually. 

table.filterExpression = {
  logic: 'AND',
  rules: [{ field: 'price', operator: 'lessThan', value: 50 }]
};
