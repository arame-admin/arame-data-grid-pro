⭐ How to Use Selected Items & Execute Batch Actions

When rows are selected using the table checkboxes, you can capture selection changes in real-time or retrieve selected rows at any time to perform bulk updates, CSV exports, API batch syncs, or deletions.

  • Event Listener: Listen to 'pdg:select' to get an array of selected primary keys (e.g. e.detail.selectedIds).
  • Get Selected Objects: Call grid.getSelectedRows() or inspect grid.selectedIds to get the full records.
  • Bulk Operations: Call grid.selectAll(), grid.clearSelection(), or grid.deleteSelectedRows().
// 1. Listen to selection changes in real time
const grid = document.querySelector('pro-data-grid');

grid.addEventListener('pdg:select', (event) => {
  const selectedIds = event.detail.selectedIds; // e.g. ['REC-101', 'REC-104']
  console.log(`User selected ${selectedIds.length} items:`, selectedIds);
  
  // Update external UI (e.g., enable/disable batch delete buttons)
  const bulkBtn = document.getElementById('myBulkActionButton');
  if (bulkBtn) bulkBtn.disabled = selectedIds.length === 0;
});

// 2. Retrieve the full row data objects for all selected items
const selectedRecords = grid.getSelectedRows();
console.log('Full selected objects:', selectedRecords);

// 3. Batch Action Example: Send selected items to a backend REST API
async function batchProcessSelected() {
  const selectedItems = grid.getSelectedRows();
  if (selectedItems.length === 0) {
    alert('Please select at least one item first.');
    return;
  }
  
  await fetch('/api/batch-update', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ ids: grid.selectedIds, items: selectedItems })
  });
}

// 4. Batch Delete / Deselect programmatically
grid.deleteSelectedRows(); // Removes selected rows and updates UI
grid.clearSelection();     // Deselects all rows
grid.selectAll();          // Selects all currently filtered rows
1. Dataset Models & Reactive Formulas

Switch between SaaS Accounts, Core Grid Fleet Telemetry, and Calculated Payroll. Calculated columns define a custom calculate(row) function that recalculates automatically whenever dependent editable fields change.

// Calculated Column Definition
{
  id: 'bonusAmount',
  header: 'Bonus Pay',
  calculate: (row) => (row.baseSalary * (row.bonusPct / 100)),
  formatter: (v) => `$${Number(v).toLocaleString()}`
}
2. Sticky First Column & Scroll Shadows

Pins the primary identifier column to left: 0 with guaranteed solid opaque layering. When the horizontal scroll offset exceeds 2px, a smooth right-edge elevation drop-shadow appears automatically.

<!-- Enable via HTML attribute or JS option -->
<pro-data-grid sticky-first-column="true"></pro-data-grid>
grid.options = { stickyFirstColumn: true };
3. Header Dropdowns & Row Context Menus

Column headers feature ⋮ menus for quick sorting, pinning, and hiding. Rows support both a visible ⋮ action button and native right-click context menu with options to duplicate, edit, or delete records.

grid.options = {
  headerMenu: true,
  contextMenu: true // Right-click or ⋮ button
};
4. Advanced Filter Rule Builder & Presets

Click ⚙️ Filter Builder to compose complex nested criteria with AND / OR match logic. Presets bar offers one-click filtered subsets with removable active chip tags.

grid.filterExpression = {
  logic: 'AND',
  rules: [{ field: 'status', operator: 'equals', value: 'Active' }]
};
5. Drag & Drop (Rows & Columns)

Grab column headers to rearrange horizontal column sequence, or drag rows using the ⠿ grip handle. Features accessible keyboard controls (Up/Down for rows, Left/Right for columns).

grid.options = {
  rowReordering: true,
  columnReordering: true
};
6. Master-Detail Row Expansion

Toggle ▶ / ▼ buttons on any row to inspect nested dossiers, vehicle diagnostics, or compensation breakdowns rendered via custom rowDetailRenderer(row).

grid.options = {
  expandable: true,
  rowDetailRenderer: (row) => `<div>VIN: ${row.vin}</div>`
};
7. Interactive Column Resizing & Auto-Fit

Drag the vertical resize bar on any column header edge to expand or shrink its width dynamically. Double-click the divider to auto-fit the column to its longest content length.

grid.options = {
  columnResizing: true // Draggable header borders + double-click auto-fit
};
8. Pinned Footer Aggregations (SUM/AVG/COUNT)

Calculate live summary totals pinned to the bottom of the table. Updates automatically whenever user filters, searches, or inline-edits cell values.

// Define aggregation in column definition
{
  id: 'arr',
  header: 'Annual Revenue',
  aggregation: 'sum', // 'sum' | 'avg' | 'min' | 'max' | 'count'
  formatter: (v) => `$${Number(v).toLocaleString()}`
}

grid.options = { footerAggregations: true };
9. Grid State Persistence (localStorage)

Persists user customizations (column widths, column order, column visibility, active sorts, and search terms) across page reloads and browser sessions.

grid.options = {
  statePersistence: true // Automatically syncs to localStorage
};
10. Clipboard TSV Copy (Excel & Google Sheets)

Copies selected rows directly to clipboard formatted with tab separators (Ctrl+C or action bar) for instant pasting into spreadsheet software.

// Programmatic TSV clipboard copy
const tsv = grid.getSelectedRowsTSV();
navigator.clipboard.writeText(tsv);
11. Right-Column Actions Pinning (Freeze Right)

Locks action buttons and context triggers on the right edge of the viewport during horizontal scrolling with drop-shadow boundary markers.

grid.options = {
  stickyActions: true // Freeze action buttons to the right edge
};
12. Bulk Batch Edit Modal

Select multiple records and update target fields (e.g., status, tier, department) in a single transaction with automatic reactive calculation re-runs.

// Open batch edit dialog or update programmatically
grid.batchUpdateSelected({ status: 'Active', tier: 'Enterprise' });
