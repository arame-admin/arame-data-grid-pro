Expandable Row Data Table Demo

Click any row or its expansion arrow (▶) to expand details directly beneath it. Supports asynchronous data loading (simulated 300ms network fetch), interactive nested buttons, keyboard navigation (Enter/Space), and single or multi-row expansion.

💡 How to Use Expandable Rows

Master-detail tables enable nesting rich sub-views, telemetry graphs, and secondary data grids beneath parent records.

1. Configure Expansion Options

Control whether single or multiple rows can expand at once, and if clicking anywhere on the row triggers expansion. 

table.options = {
  multiExpand: true,
  expandOnRowClick: true
};

2. Async or Synchronous Details

Supply an async function or HTML generator returning sub-tables, telemetry metrics, or action panels. 

table.detailRenderer = async (row) => {
  const data = await fetchSubData(row.id);
  return `<div>Telemetry: ${data.temp}°C</div>`;
};
