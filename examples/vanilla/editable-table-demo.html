💡 How to Use In-Place Cell Editing

Allows users to update table values directly without modals. Supports input editors (text, number, select, checkbox), synchronous field validation, and keyboard shortcuts.

1. Configure Editors & Validators

Specify editable: true, choose an editor type, and optionally supply a custom validator(val) function returning an error string. 

{
  id: 'price',
  editable: true,
  editor: { type: 'number', min: 0 },
  validator: (v) => (v < 0 ? 'Cannot be negative' : null)
}

2. Save Events & Keyboard Controls

Press Enter to save or Esc to cancel. Listen to the et:save CustomEvent to sync changes back to your backend. 

table.addEventListener('et:save', (e) => {
  const { rowId, columnId, newValue } = e.detail;
});
