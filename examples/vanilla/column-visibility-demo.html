💡 How to Use Column Visibility

Give users full control over table density by letting them customize visible columns with automatic localStorage persistence.

1. Define Columns with Locked Keys

Mark critical identifier columns as required: true to prevent users from accidentally hiding primary identification keys. 

table.columns = [
  { id: 'name', header: 'Employee', required: true },
  { id: 'salary', header: 'Salary', visible: false }
];

2. Persistence & Batch Actions

Provide users with instant "Show all" and "Hide optional" buttons alongside automatic localStorage caching. 

table.options = {
  storageKey: 'user-preferences-v1'
};
