Tree Data Table (Hierarchical Web Component)

Displays multi-level nested records with expandable and collapsible relationships, sticky parent headers during scroll, drag-and-drop row reordering, cascading checkbox selection, global search across hierarchy, and CSV export.

💡 How to Use the Tree Data Table

Tree tables represent nested hierarchical data (e.g. Work Breakdown Structures, File Trees, Nested Project Tasks) with expanding nodes, drag and drop, and cascading selection.

1. Hierarchical Data Structure

Data can be passed as nested arrays using a children property, or as a flat list with parentId pointers. 

const data = [
  { id: '1', title: 'Phase 1', children: [{ id: '1.1', title: 'Scoping' }] }
];
treeTable.data = data;

2. Cascading Selection & Reordering

Checking a parent node automatically cascades selection down through its children with indeterminate state representation on partial selection. 

treeTable.options = {
  cascadingSelect: true,
  dragAndDrop: true
};
