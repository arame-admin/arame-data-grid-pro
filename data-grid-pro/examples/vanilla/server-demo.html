💡 How to Use Server-Side Data Loading

Offload query execution, filtering, multi-sort, and pagination to an API endpoint with request cancellation and loading spinners.

1. Define Server Loader Callback

Supply an async function to grid.dataLoader that receives pagination, sorting, search terms, and an AbortSignal. 

grid.dataLoader = async ({ page, pageSize, sort, search, signal }) => {
  const res = await fetch(`/api/fleet?page=${page}&q=${search}`, { signal });
  return await res.json(); // { rows, total }
};

2. Request Cancellation & Loading

Rapid user keystrokes automatically abort in-flight HTTP requests via signal, while showing an indeterminate top progress bar. 

grid.refresh(); // Triggers server query re-fetch
