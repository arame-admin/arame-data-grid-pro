Data Table Beginner Guide & Reference

Learn how to install, register, and configure interactive data tables in simple, everyday language. Works in plain HTML, Next.js, React, Vue, Svelte, or any other web tool.

1. What is this library for?

Whenever you build a website or dashboard, you often need to show lists of items—like customer contacts, store products, or financial reports.

arame-data-grid-pro gives you ready-made data tables that come with search bars, sortable headers, page buttons, and cell editing built right in.

Works Anywhere

Built with standard browser Web Components. Use it directly in regular HTML, or inside modern frameworks like Next.js, React, and Vue without needing special plugins.

No Extra Styling Dependencies

Everything is styled cleanly out of the box. You do not need to install Tailwind CSS or any external theme library.

13 Specialized Table Types

Includes sticky columns, expandable details, hierarchical trees, and live payroll calculators with instant math formulas.

Ready to Use Immediately

Search, column sorting, and pagination work out of the box with zero complex setup.

2. Key Terms Explained Simply

If you are new to web development, here is what these common terms mean:

  • Web Component / Custom Element: A custom HTML tag defined with JavaScript (like <pro-data-grid>). The browser recognizes it and behaves just like native HTML tags such as <button> or <table>.
  • Client-Side Data: All your data is already downloaded into the user's browser. Searching and sorting are instant because your visitor's computer does all the work.
  • Server-Side Data: Your data lives in a database on a remote server. The table only downloads a small batch of rows (like 10 or 25) at a time when someone types in search or clicks next page.
  • Debounce (searchDebounceMs): A brief delay (e.g., 300 milliseconds) that waits for the user to pause typing before sending a search request, preventing too many unnecessary network queries.
  • AbortSignal: A browser feature that stops old search requests if a user types a new character before the previous result finishes loading.
  • Events: Notifications the table sends when a user does something, such as clicking a row, saving an edit, or deleting an item.

3. Prerequisites & System Requirements

arame-data-grid-pro is designed with lightweight, native browser standards. Before integrating, review the minimum requirements:

Modern Web Browsers

Native Custom Elements v1 and modern JavaScript (ES2020+) are supported across:

  • Chrome / Edge / Chromium v75+
  • Firefox v63+
  • Safari v12.1+ (macOS & iOS)

Node.js & Package Tools

If installing via package managers or building from source:

  • Node.js v18.0.0 or higher (Node LTS v20+ recommended)
  • npm, pnpm, or yarn
  • TypeScript 5.0+ (optional, for type checking)

Zero External CSS / Frameworks

No Tailwind, Bootstrap, React, or Vue dependencies are needed. All layout, animations, and theming run on standalone CSS.

Offline & file:/// Ready

All standalone demos run out-of-the-box locally without needing a web server or bundler step.

4. Installation

You can install the library into an existing project using npm, pnpm, or yarn: 

# Using npm:
npm install arame-data-grid-pro

# Using pnpm:
pnpm add arame-data-grid-pro

# Using yarn:
yarn add arame-data-grid-pro

Build & Test Commands

If you are working directly in this repository, you can use these commands: 

npm run build      # Builds the library files and type declarations
npm test           # Runs the project test suite
npm run typecheck  # Checks for any TypeScript errors
No server needed for demos: You can open any file in the examples/vanilla/ folder (such as gallery.html) directly in your browser with a double-click.

5. 5-Minute Quick Start

Here is a complete, working HTML example you can save as index.html and open in your browser: 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>Data Grid Quick Start</title>
  <!-- Include the default stylesheet -->
  <link rel="stylesheet" href="../../dist/styles.css" />
</head>
<body style="font-family: sans-serif; padding: 2rem;">

  <h1>Team Directory</h1>

  <!-- 1. Add the custom element tag to your HTML -->
  <pro-data-grid id="myGrid"></pro-data-grid>

  <!-- 2. Configure columns and rows in JavaScript -->
  <script type="module">
    import '../../dist/index.js';

    const grid = document.getElementById('myGrid');

    // Define the columns you want to display
    grid.columns = [
      { id: 'id', header: 'ID', field: 'id', width: '80px' },
      { id: 'name', header: 'Full Name', field: 'name', sortable: true },
      { id: 'role', header: 'Role', field: 'role', sortable: true },
      {
        id: 'salary',
        header: 'Salary',
        field: 'salary',
        sortable: true,
        formatter: (val) => `$${Number(val).toLocaleString()}`
      }
    ];

    // Provide your row data
    grid.rows = [
      { id: '1', name: 'Alice Walker', role: 'Engineering Lead', salary: 145000 },
      { id: '2', name: 'Brian Miller', role: 'Product Manager', salary: 130000 },
      { id: '3', name: 'Clara Patel', role: 'UX Designer', salary: 115000 }
    ];
  </script>
</body>
</html>

Main Table Options

Set options using grid.options = { ... }:

grid.options = {
  pagination: true,           // Enable pagination bar at bottom
  pageSize: 10,               // Number of rows per page
  searchable: true,           // Enable global search box
  editable: true,             // Enable double-click cell editing
  deletable: true,            // Show delete buttons on rows
  confirmDelete: true,        // Ask user before deleting a row
  rowReordering: true,        // Enable dragging rows up or down
  columnReordering: true,     // Enable dragging headers left or right
  columnResizing: true,       // Enable draggable column width resizers
  stickyFirstColumn: true,    // Freeze first column on left
  stickyActions: true,        // Freeze actions column on right
  footerAggregations: true,   // Pinned summary aggregations (SUM/AVG)
  statePersistence: true      // Sync settings & layout to localStorage
};

7. Loading Data: Client-Side vs. Server-Side

Client-Side Data (Simple & Fast)

For smaller datasets (hundreds or thousands of rows), assign your array directly to grid.rows: 

grid.rows = [
  { id: '1', name: 'Desk Chair', price: 189.99 },
  { id: '2', name: 'Monitor Arm', price: 79.50 }
];

Server-Side Data (For Large Databases)

For large datasets, set serverSide: true and provide a serverDataLoader function. The table calls this function automatically whenever the user changes pages, types in search, or sorts columns: 

grid.options = {
  serverSide: true,
  searchDebounceMs: 300,              // Wait 300ms after user stops typing
  keepPreviousDataWhileLoading: true, // Keep showing previous rows while loading

  serverDataLoader: async (params) => {
    // params provides: pageIndex, pageSize, globalSearch, sortCriteria, and signal
    const query = new URLSearchParams({
      page: String(params.pageIndex),
      limit: String(params.pageSize),
      q: params.globalSearch || ''
    });

    // Pass params.signal so outdated requests cancel automatically
    const res = await fetch(`/api/products?${query}`, { signal: params.signal });
    const json = await res.json();

    // Always return rows for this page and total count of all matching records
    return {
      rows: json.items,
      totalRows: json.totalCount
    };
  }
};

9. Events & Accessibility

The table triggers standard browser events you can listen to with JavaScript:

Event Name What it does Example Detail Data
pdg:select Fires when rows are checked or unchecked { selectedIds: ['1', '3'] }
pdg:sort Fires when someone clicks a column to sort { criteria: [{ columnId: 'name', direction: 'asc' }] }
pdg:page Fires when the user changes page or page size { pageIndex: 2, pageSize: 10 }
pdg:edit-save Fires when someone saves an edited cell { rowId: '1', columnId: 'role', newValue: 'Director' }
pdg:delete Fires when a row's delete button is clicked { rowId: '4', row: { ... } }

Handling Selected Items & Bulk Actions

Listen to pdg:select to capture selected row identifiers, retrieve full objects, or perform batch operations: 

// 1. Listen for selection changes in real-time
grid.addEventListener('pdg:select', (event) => {
  const selectedIds = event.detail.selectedIds; // e.g. ['1', '3']
  console.log(`${selectedIds.length} rows selected:`, selectedIds);

  // Toggle batch action button state
  const btnDeleteAll = document.getElementById('btnBatchDelete');
  if (btnDeleteAll) btnDeleteAll.disabled = selectedIds.length === 0;
});

// 2. Retrieve the complete row data records for selected items
const selectedRows = grid.getSelectedRows();
console.log('Selected row records:', selectedRows);

// 3. Batch delete or clear programmatically
grid.deleteSelectedRows(); // Removes selected rows and updates UI
grid.clearSelection();     // Deselects all rows
grid.selectAll();          // Selects all currently filtered rows

Accessibility (A11y) Built-in

  • Keyboard Friendly: Move through cells using arrow keys, open editors with Enter, and toggle checkboxes with Space.
  • Screen Readers: Standard ARIA roles (role="grid", role="row", role="columnheader") announce cell information clearly.
  • Respects Motion Preferences: If someone turns on "Reduce motion" in their operating system, animations are automatically disabled.

10. Simple Troubleshooting

1. "Access to script at 'file:///...' has been blocked by CORS policy"

Why this happens: Browsers do not allow import statements between separate local files when opened directly with file:///.
How to fix it: All demo files in examples/vanilla/ have their scripts placed inline so you can double-click them right from your folder without any error. If you write your own files, run a small local server with npx serve or Vite.

2. "window is not defined" or "customElements is not defined" in Next.js

Why this happens: Next.js tries to run your page on the server first, where there is no browser window.
How to fix it: Put 'use client'; at the top of your component file, and configure your table inside a useEffect() hook.

3. The table has no styles or looks like plain text

Why this happens: The CSS stylesheet is not linked.
How to fix it: Add <link rel="stylesheet" href="./dist/styles.css" /> in HTML or import 'arame-data-grid-pro/styles.css'; in your JS/TS code.
