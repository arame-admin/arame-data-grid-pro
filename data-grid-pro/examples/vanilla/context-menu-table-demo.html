• Row Context Menu: Right-click any row (or click the row's ⋮ button on touch/pointer) to open row actions (View, Edit, Duplicate, Delete).

💡 How to Use Header & Context Menus

Provides clean dropdown menus for column sorting/pinning/hiding and native right-click row context actions for contextual workflow execution.

1. Column Header Actions

Click the ⋮ icon on column headers to sort Ascending/Descending, pin left or right, or toggle column visibility checkboxes. 

table.options = { headerMenu: true };

2. Row Context Menus

Right-click any row to display quick actions like "Duplicate Record", "Edit Record", or "Delete Record" with safe viewport edge clamping. 

table.addEventListener('cmt:row-action', (e) => {
  console.log(e.detail.action, e.detail.row);
});
