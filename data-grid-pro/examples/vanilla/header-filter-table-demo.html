In-Header Filter Data Table

A framework-agnostic Web Component with in-header filters: text (debounced), select dropdowns, multi-select checkboxes, number ranges, and date ranges. Combines with global search, column sorting, pagination, and resizable columns.

💡 How to Use In-Header Filters

Embed dedicated filtering widgets directly inside the second row of the table header without requiring separate toolbar drawers.

1. Configure Header Filter Widgets

Assign filter: { type: 'text' | 'select' | 'multi-select' | 'number-range' | 'date-range' } in column metadata. 

{
  key: 'genre',
  header: 'Genre',
  filter: { type: 'select', options: ['Action', 'Drama', 'Sci-Fi'] }
}

2. Automatic Debounced Execution

Inputs are automatically debounced (250ms) to ensure instantaneous UI updates without keystroke lag or stutter. 

table.addEventListener('hft:filter-change', (e) => {
  console.log('Active Filters:', e.detail.filters);
});
