💡 How to Use the Core Grid

The Core Grid provides the foundational, zero-dependency Web Component implementation for high-volume enterprise data tables. Below is how its primary capabilities are initialized and configured in code:

1. Initialize & Bind Columns

Define column definitions with id, header, field, and optional flags like sortable, renderer, and formatter. 

const grid = document.getElementById('grid');
grid.columns = [
  { id: 'vin', header: 'VIN', field: 'vin', sortable: true },
  { id: 'status', header: 'Status', field: 'status', renderer: renderBadge }
];
grid.rows = dataset;

2. Selection & Master-Detail

Configure row selection checkboxes and expandable detail accordions via grid.options. 

grid.options = {
  selectable: true,
  multiSelect: true,
  expandable: true,
  rowDetailRenderer: (row) => `<div>VIN: ${row.vin}</div>`
};

3. Sorting & Search Engine

Click any sortable column header to toggle ascending/descending, and type in the search bar for instant debounced global filtering. 

grid.addEventListener('pdg:select', (e) => {
  console.log('Selected IDs:', e.detail.selectedIds);
